<h1>Bus Reservation System</h1>
<p>
  <a> A CLI - based Bus reservation system made using Java and MySql as database with JDBC to connect both. </a>
</p>


<h1>Features</h1>


- Quick sign-up and login with PBKDF2 password hashing
- Search buses by route and view fare/capacity
- Visual seat layout with booked/available legend
- Transaction-safe bookings and cancellations
- Booking history and account management
